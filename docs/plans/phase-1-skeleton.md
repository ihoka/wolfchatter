# Phase 1 — Skeleton Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A bootable Rails 8.1 app on PostgreSQL with Tailwind, the full local quality toolchain
(Minitest, headless-Chromium system tests, RuboCop, Brakeman, bundler-audit, Prosopite, SimpleCov),
a README, and the map page's empty state.

**Architecture:** Stock `rails new` with unused frameworks skipped, so later phases only add domain
code. The root route is `chatrooms#index`, which renders the full-screen map container and the
floating panel in its empty state — the page phase 2 builds on.

**Tech Stack:** Ruby 3.4.5, Rails 8.1.4, PostgreSQL (local socket), importmap, tailwindcss-rails,
Minitest, Capybara + Selenium (headless Chromium), Prosopite + pg_query, SimpleCov.

**Spec:** [`docs/superpowers/specs/2026-11-09-wolfchatter-design.md`](../superpowers/specs/2026-11-09-wolfchatter-design.md) · PRD: [`docs/prd.md`](../prd.md)

## Global Constraints

- Ruby 3.4.5 (`.ruby-version`), Rails 8.1.4. No Redis, no Node/JS bundler, no CI workflow, no Kamal.
- Solid Queue is the Active Job adapter in development and production (so `limits_concurrency` applies everywhere jobs really run); test uses the `:test` adapter. Solid Cable is the Action Cable adapter in development and production: in development Solid Queue's Puma plugin forks separate processes, and `broadcast_*_later` jobs run there, so the in-process `async` cable adapter would never reach browsers. Test keeps the `test` cable adapter.
- `.mise.local.toml` must stay git-ignored.
- Branch: `phase-1-skeleton`. One PR into `main`, merge commit.
- Docs are written for the product team. Requirements come from the product request. Istvan Hoka is the lead engineer and signs off every checkpoint.

## Review Focus

- `rails new --force` overwrites `.gitignore` — Task 1 re-adds `.mise.local.toml`; reviewer checks `git status` doesn't show it.
- System tests silently not running (Rails 8.1 no longer generates them by default) — Task 2 adds a smoke system test that must *fail first*.
- Selenium can't locate Chromium on this machine — Task 2 supports a `CHROME_BIN` override and documents it in the README.
- SimpleCov under parallel tests reports partial coverage — coverage only runs with `COVERAGE=1`, which forces a single worker.
- Prosopite must cover both thread models — `setup { Prosopite.scan }` covers model/job/integration tests (same thread); the Rack middleware in `config/environments/test.rb` covers system tests, where requests run in Puma's thread.
